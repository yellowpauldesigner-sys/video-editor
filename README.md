# uberdesigner clips — браузерная версия

Видеоредактор для дизайнеров, который работает целиком во вкладке браузера: без установки, без терминала и без
сервера. Клип и его файлы хранятся в самом браузере, видео собирается там же.

## Что умеет

- **Таймлайн.** Сцены и слои (видео, картинка, текст, фигура), обрезка краями, перестановка, `S` — разрезать,
  пробел — пуск, ⌘Z — шаг назад, «История» — точки возврата.
- **Запись вкладки.** Кнопка «Записать вкладку»: браузер спрашивает, какую вкладку показать, запись попадает в
  клип новой сценой. Идёт в реальном времени — плавность зависит от компьютера.
- **Форматы.** 16:9, 9:16, 1:1, 4:5 из одного клипа; положение и кадрирование слоя у каждого формата свои.
- **Сборка.** MP4 (H.264) со звуком, все отмеченные форматы подряд, файлы скачиваются по ссылке.

## Где работает

Chrome и Edge на компьютере. Сборка видео использует WebCodecs: в Safari и Firefox монтаж откроется, но сборка
может быть недоступна — редактор скажет об этом сам. Звук кодируется в AAC, а где браузер этого не умеет — в Opus
(QuickTime такой звук не играет; редактор помечает такие файлы).

## Как выложить

Это статический сайт без сборки: папку можно отдать любому хостингу.

- **Vercel:** импортировать репозиторий, Framework Preset — Other, команды сборки нет, Output Directory — корень.
- **Локально, чтобы посмотреть:** `npx serve .` или `python3 -m http.server 5500` в этой папке, затем открыть
  напечатанный адрес. С `file://` не откроется: браузер не загружает модули с диска.

Запись вкладки и сборка видео работают только на `https://` или `localhost`.

## Устройство

| Файл | Что делает |
|---|---|
| `js/model.mjs` | Формат клипа, тайминг, проверка. Тот же файл, что в скилле uberdesigner clips |
| `js/renderer.js` | Сцена: рисует кадр клипа на canvas. Её показывает редактор и её же снимает сборка |
| `js/export.js` | Сборка: кадры → H.264 (WebCodecs), звук → сведение и кодирование |
| `js/mp4.js` | Запись MP4-файла из закодированных кусков |
| `js/media.js` | Разбор входящих файлов, миниатюры, запись вкладки |
| `js/store.js` | Хранение в IndexedDB: клипы, файлы, история |
| `js/app.js` | Редактор: слои, кадр, таймлайн, свойства |

Зависимостей нет. Шрифт Instrument Sans — под SIL Open Font License (`fonts/OFL.txt`).

## Чего нет

- Покадровой записи сайта по сценарию: браузер не даёт вкладке управлять временем чужой страницы. Она есть в
  локальном скилле uberdesigner clips.
- Изменений через Claude, ключевых кадров сложнее одного медленного движения на слой, масок, цветокоррекции.
- Переноса клипа между браузерами и компьютерами: клип живёт там, где его сделали.
- Видео в ProRes и HEVC: браузер их не проигрывает, такие файлы нужно пересохранить в MP4 (H.264).
